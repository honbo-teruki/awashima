# 三ツ目のデザイン（三ツ目株式会社）

「三ツ目のデザインで」「みつめのデザインで」と言われたときに使う。見本は三ツ目の提案資料（2026年11月「魚沼市ふるさと納税 寄附拡大のご提案」）で、その pptx を `mitsume/template.pptx` として入れてある（個人の氏名・顔写真・連絡先・ノートの議事録は外し、［氏名］などの仮置きにしてある）。デザインは見本の完全なコピーにする。自分で描き直さない。

## 作り方（必ずこの手順）

1. **PowerPoint（.pptx）で作る**。`mitsume/mitsume_deck.py` を使い、`template.pptx` のレイアウトにページを足す。表紙の赤枠と斜線、本文ページの角の3本線、締めの赤い面、タイトルの位置・色・大きさは、レイアウトに入っているので触らない
2. 形が見本にあるページは、`clone(番号)` で見本のスライドを複製し、`replace()` で文字だけを差し替える。新しく組むのは、見本に近い形がないときだけ
3. 新しく組むときは、`mitsume_deck.py` の部品（`toc` `cards3` `points3` `point_boxes` `kpi` `bars` `table` `memo` `note`）を使う。寸法は見本から測ってある
4. 仕上げに LibreOffice で PDF にして全ページを画像で確かめ、文字のはみ出しと、言葉の途中での改行がないかを見る。Meiryo がない環境では字幅が広く出るので、そこで収まっていれば PowerPoint でも収まる
5. pptx と PDF の両方を渡す。書体は Meiryo のまま変えない（Googleスライドで開くと別の書体に置き換わるので、文字のはみ出しだけ確かめるよう一言添える）
6. 人の名前・写真・連絡先は、依頼の中で渡されたものだけを入れる。見本の［氏名］［写真］はそのまま残さず、渡された情報に替えるか黄色のメモで依頼する

```python
import sys; sys.path.insert(0, "<スキルのフォルダ>/brands/mitsume")
from mitsume_deck import Deck
d = Deck()
d.cover("魚沼市ふるさと納税\n寄附拡大のご提案", "2026年11月20日　三ツ目株式会社")
s = d.content("資料の目次"); d.toc(s, ["会社紹介", "実績と事例紹介", "ご提案", "その他支援事例"])
s = d.clone(3)                       # 会社概要
s = d.content("結果を分けたポイント", "需要期の前に「売れる準備」を終えていたかどうか")
d.point_boxes(s, ["POINT 1\n…", "POINT 2\n…", "POINT 3\n…"])
d.memo(s, "POINT 2・3の中身を入れてください")
d.thanks("三ツ目株式会社\n［担当者名］", "【連絡先】\n［電話番号］\n［メールアドレス］")
d.save("out.pptx")
```

## 見本から測った値（1920×1080のpx、文字はpt）

- 色：赤 #FF0000、ピンク #FFB7B7、淡いピンク #FFEAEA、本文 #333333、補足 #595959、注記 #666666。影・グラデーションはない
- 書体：Meiryo（和文・英数字とも）
- 表紙：赤枠（幅45pxの帯を四辺に）、斜線は幅28pxの赤い帯3本を20.4度傾けて、ロゴの後ろを上から下まで通す（「／」の向き）。タイトルは赤42pt太字・中央揃え（x93 y304 w1136）、日付と社名は赤20pt太字
- 本文ページ：タイトルは左上（x65 y45）赤28pt太字、その下（y166）に赤18pt太字のリード。角の3本線は幅28px×長さ365pxの赤い帯を135度傾けて右上と左下に3本ずつ（「＼」の向き）。ページ番号は右下10pt
- 赤枠のページ：表紙と同じ赤枠で、斜線なし（代表プロフィール用）
- 締め：右半分（x960〜）が赤の面に白抜きロゴ、左に「Thank you!」赤42ptと連絡先
- 本文の文字：10〜11pt #333333、見出し14〜20pt太字、強調は赤の太字
- 表：見出し行は赤地に白の太字11pt、強調する行はピンク地
- 黄色のメモ：地 #FFF6CC、枠 #D9A400 1pt、文字 #6B4E00 太字10pt、「✎ 入れてください｜」で始める

## 中身の決まり

- 渡されていない数字・名前・事例は作らない。本文には［人口］［00.0%］のように角かっこで仮置きし、何を入れるかを黄色のメモに書く（見本と同じやり方）
- 出典は各ページ下に8pt #666666で1〜2行
- natural-slides の色・線・余白・文字サイズの決まりは、このデザインでは使わない（見本に合わせる）。コピーの書き方（言い切る、中身のない言い回しを避ける、言葉の途中で改行しない）は natural-slides に従う
