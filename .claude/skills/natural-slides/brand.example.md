# ブランド設定

natural-slidesは、このフォルダに`brand.md`があればその値で資料を作り、最初の質問を飛ばす。使うときはこのファイルを`brand.md`という名前でコピーし、値を書き換える。書いていない項目は既定値になる。

| 項目 | 値 |
|---|---|
| メインカラー | #2F3237 |
| 書体（欧文・数字） | Montserrat |
| 書体（和文） | Noto Sans JP |
| ロゴ | なし |
| 会社名・サービス名 | なし |
| 主な出力先 | PDF |

ロゴには画像ファイルのパスかURLを書く。主な出力先はPDF・PowerPoint・Googleスライド・Canvaのどれか。
